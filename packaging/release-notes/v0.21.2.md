ZapFast Windows 11 visual edition, based on the complete original client.

- WhatsApp emoji artwork replaces the Windows emoji style, including the picker and reactions.
- Window material can be selected in Appearance: Mica, Acrylic, or solid, with opaque fallback on unsupported systems.
- More Windows Fluent icons, retaining original fallbacks and delivery indicators.
- Windows updates use walmirramos/zapfast and a separate signed update channel, so an official upstream binary cannot replace this edition's appearance.
- The installer offers to open ZapFast when it finishes.

Account, messaging, call, media and archive behavior is retained. Emoji artwork
provenance and terms are documented in packaging/WHATSAPP_EMOJI.md. Native
materials require Windows 11 build 22621 or later; older Windows uses solid
surfaces. This community build is not Microsoft, WhatsApp or Meta software.
